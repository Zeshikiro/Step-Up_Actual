What to Add: A visual safety warning text.
Where to put it:
* Open SampleScene in the Unity Editor.
* Find your AR UI Canvas (the canvas that contains the "Exit AR" button).
* Add a new UI -> Text (TextMeshPro) element.
* Set the text to: "WARNING: Stay aware of your surroundings!"
* Position it at the top or bottom of the screen. No coding is required; it just needs to be visible in AR mode.

--- 3. Incomplete: Forgot Password Flow ---
According to the Paper (Page 45, Item 1): "User Registration and Login System - The application allows users to create an account and securely log in..."
Current Status in App: The code for sending a password reset email (SendPasswordResetEmail) exists inside AuthManager.cs, but it is not connected to your UI button.
What to Add: Wire the existing script to the UI button.
Where to put it:
* Open LoginScene in the Unity Editor.
* Select your "Forgot Password" button in the Hierarchy.
* In the Inspector, scroll down to the Button component and find On Click ().
* Drag your AuthManager GameObject into the slot.
* Click the dropdown and select AuthManager -> SendPasswordResetEmail().

--- 4. Mismatched: UI Stretching on Mobile Phones ---
Current Status in App: As noted earlier, the Tutorial UI looks perfectly stretched on a PC (16:9 ratio), but looks squished or leaves huge gaps on modern Android phones (20:9 ratio).
What to Fix: You need to balance the Canvas Scaler so it stretches correctly on taller screens.
Where to put it:
* Open SampleScene in the Unity Editor.
* Click on the main Canvas (or tutorialcanvas).
* In the Inspector, look at the Canvas Scaler component.
* Change "Match Width Or Height" from 0 to 0.5.
* Repeat this exact same process for the Canvas in CustomizeScene.
